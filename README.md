# 👓 SpecSpy

A Smart Glasses Tracking System developed using Spring Boot.

## 📖 Overview

SpecSpy helps users locate and manage their smart glasses through a modern web interface. The application simulates Bluetooth connectivity and provides tracking, location viewing, ringing, and profile management features.

---

## ✨ Features

- 🔐 User Registration & Login
- 📊 Interactive Dashboard
- 📶 Bluetooth Status Simulation
- 🔍 Locate Smart Glasses
- 📍 Last Known Location
- 🗺️ Google Maps Integration
- 🔔 Ring Smart Glasses
- 🎤 Voice Assistant
- 👤 User Profile
- ⚙️ Settings Page

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/ushasree30/SpecSpy.git
```

2. Open the project in VS Code or IntelliJ IDEA.

3. Configure MySQL in `application.properties`.

4. Run:

```bash
mvn spring-boot:run
```

5. Open:

```
http://localhost:8080
```
